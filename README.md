# Back-End Development and APIs Certification - freeCodeCamp

This repository contains my projects and exercises completed during the freeCodeCamp Back-End Development and APIs Certification.

- Node.js fundamentals and the event-driven runtime

- Node Package Manager (npm)

- WebSockets and real-time communication
- Security and privacy best practices
